waowao プライバシーポリシー

最終更新日: 2026年11月20日 | English

「waowao」(以下「本アプリ」)は、Pakyun LLC(以下「開発者」)が提供するアプリです。本アプリにおける利用者情報の取り扱いについて、以下のとおり定めます。

1. 基本方針 — 開発者はあなたのデータを受け取りません

  • 開発者が運営するサーバーは存在しません。 カメラの映像も、顔から読み取った情報も、撮った動画も、開発者に送信されることはありません。
  • アカウント登録・ログインはありません。

2. カメラの扱い

  • 前面カメラは、自分の顔を画面に映し、顔の動きに合わせて映像を変形させ、音を鳴らすために使用します。
  • 「こわれた かがみ」のカーブミラーでは、背面カメラも同時に使用し、鏡のまわりにその場の景色を映します。背面カメラの映像から顔や人物を読み取ることはありません。
  • 映像の処理はすべてお使いの端末の中で行われます。映像を端末の外に送ることはありません。
  • マイクは使用しません。動画に入る音は、本アプリが端末の中で合成した音だけです。

3. 顔データについて(TrueDepth カメラ / 顔認識)

  • 取得するもの: 本アプリは、端末の顔認識機能(iOS では ARKit の顔追跡。TrueDepth カメラを使う機種があります)から、顔の部品のおおよその位置(目・鼻・口・あご・額)と、表情の度合いを表す数値(口の開き、眉の上がり、目の開き、口のすぼめ、笑顔、片目のまばたき、口の左右、舌、首の傾き、顔の近さ)を読み取ります。
  • 使いみち: 画面に映す自分の顔を変形させることと、それに合わせて音を鳴らすことだけに使います。本人の識別、顔認証、顔のテンプレートの作成、広告、分析には使いません。
  • 保存と共有: これらの位置や数値は、その瞬間の画面を描くためにメモリ上で使うだけで、保存しません。端末の外へ送信しません。第三者と共有しません。 広告 SDK にも渡しません。
  • 保持期間: 次の映像が来るたびに上書きされ、アプリを閉じると残りません。

4. 録画した動画

  • 録画は、利用者が録画の操作をした時、または「3コマ」を始めた時にだけ行います。録画中は画面に赤い印が出ます。
  • 録画した動画(変形後の映像と合成した音)は、まず端末内の一時的な場所に置かれます。利用者が「保存」を選ぶと端末の写真ライブラリに保存され、「共有」を選ぶと利用者が選んだ先に渡されます。どちらも選ばずに画面を離れると、一時ファイルは削除されます。
  • 写真ライブラリへのアクセスは「追加のみ」で、保存済みの写真や動画を本アプリが読むことはありません。

5. 広告について

本アプリは広告表示のために Google AdMob を使用しています。AdMob は広告配信のため、以下の情報を取得することがあります。

情報目的
広告識別子(iOS: IDFA ※トラッキング許可時のみ / Android: 広告 ID ※端末の設定でリセット・削除できます)広告のパーソナライズ・効果測定
IPアドレス・おおよその位置情報地域に応じた広告配信
端末情報(機種・OSバージョン等)広告の表示最適化・不正防止
  • カメラの映像や顔データを、広告の配信やターゲティングに使用することはありません。
  • トラッキングの許可はiOSのダイアログでいつでも拒否・変更できます(設定 > プライバシーとセキュリティ > トラッキング)。拒否しても本アプリの全機能を利用できます。
  • Googleによるデータの取り扱いは Googleのポリシーと規約 をご確認ください。

6. データの削除

本アプリのデータはすべて端末内にあります。アプリを削除すると、保存された設定はすべて削除されます。写真ライブラリに保存した動画は、写真アプリから削除できます。
